# Student Performance Analysis 

## About the Project
This is a Data Analytics project using Python.
The project analyses student marks in different subjects.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- ## Analysis Performed

- Checked dataset information
- Checked missing values and duplicates
- Calculated total marks
- Calculated average marks
- Found highest and lowest student averages
- Compared subject performance

## Visualizations

1. Average Marks by Subject
2. Student Performance Comparison
3. Distribution of Student Marks

## Key Findings

- Class average: 80.53
- Highest student average: 87.67
- Lowest student average: 70
- English has the highest subject average.
